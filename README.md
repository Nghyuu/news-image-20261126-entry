A one-page newspaper front page — "THE WORLD TODAY" — summing up Thursday
26 November 2026: the US tariff plan, Shenzhou-24 carrying Pakistan's first
astronaut, 20 hostages freed in Colombia, North Korea ordering the Swiss office
shut, Mumbai marking 18 years since 26/11, a Champions League night of goals,
and oil jumping as Asian markets steadied. Drawn from scratch by a
pure-TypeScript rasterizer (hand-written 5x7 bitmap font, hand-written PNG
encoder), Node stdlib only. Run with `MAKEFUN_OUTPUT_DIR=out node main.ts`.
